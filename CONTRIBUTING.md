# Contributing to Healthy Inc.

Thank you for your interest in contributing to Healthy Inc.! We welcome open-source contributions to our public integration modules, Web3 demonstration frameworks, and documentation.

## Code of Conduct
By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute
1. **Fork the Repository:** Create your own fork of the target public repository.
2. **Create a Feature Branch:** `git checkout -b feature/your-feature-name`
3. **Commit Your Changes:** Write clean code with concise, documented commit messages.
4. **Submit a Pull Request:** Open a PR against `main` for team review and automated verification.

# Security Policy

## Reporting a Vulnerability

Healthy Inc. takes cybersecurity, data privacy, and HIPAA zero-trust compliance extremely seriously.

If you discover a potential security vulnerability within any public-facing Healthy Inc. integration, smart contract wrapper, or open-source module, please do **NOT** report it publicly through GitHub Issues.

### Reporting Procedure
Please report all security vulnerabilities directly to our security orchestrators:
* **Email:** `security@healthy.inc`

### Vulnerability Report Checklist
When submitting a report, please include:
1. Description of the vulnerability and its potential impact.
2. Steps to reproduce the issue (proof-of-concept code or CLI steps).
3. Any suggested remediations or mitigations.

Our security team will acknowledge receipt of your report within 24 hours and provide an estimated resolution timeline.
